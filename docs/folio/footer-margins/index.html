Working recommendation

Your pick: none yet

  1. Prefer C if you want “text below a border” without spending a full row: solid hairline + small top pad on panel ground.
  2. Prefer F if you want to keep the dotted engraved-caption language and soften the clash with the full-bleed olive strip.
  3. Avoid D if the bar already feels strip-like — symmetric padding reintroduces statusline energy.
  4. Do not restyle or hide the olive bar here; that chrome belongs to the program in the viewport.
